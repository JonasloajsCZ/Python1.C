Doporučení oblečení podle teploty

Jednoduchý program v Pythonu, který se zeptá na aktuální teplotu a doporučí vhodné oblečení.

Jak se spouští:
Spusť soubor pocasi.py a zadej teplotu jako celé číslo.

Rozsahy teplot:
25 a více: tričko a kraťasy
15 až 24: lehká mikina
5 až 14: bunda
méně než 5: zimní kabát a čepice
