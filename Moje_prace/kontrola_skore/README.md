Kontrola skóre

Jednoduchý program v Pythonu, který zkontroluje číslo skóre (0 až 100) a vypíše výsledek.

Jak se spouští:
V souboru kontrola_skore.py uprav proměnnou skore a spusť příkaz python kontrola_skore.py.

Výsledky:
mimo 0 až 100: neplatné skóre
90 a víc: výborný výsledek
50 až 89: splněno
0 až 49: nesplněno
